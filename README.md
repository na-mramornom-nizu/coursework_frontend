# Coursework frontend

HTML-шаблоны Jinja2, CSS и JavaScript интерфейса учебного ПВЗ. Этот репозиторий нужно разместить рядом с `coursework_backend` и `coursework_sql`; Flask берёт шаблоны и статические файлы напрямую из него.

Страницы охватывают вход, настройку процессов, работу с заказами и просмотр траектории. Формы обращаются к маршрутам Flask; для работы интерфейса необходимы `coursework_backend` и база из `coursework_sql`.
